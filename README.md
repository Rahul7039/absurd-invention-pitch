One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance — a houseplant that texts your landlord a photo of itself whenever you forget to water it for a week. Entry for make.fun's "One-Sentence Absurd Invention Pitch" bounty ($2.50 pot, top 10 share it).

## Run it

```sh
python3 main.py
```

Writes the pitch (99 characters, one sentence) to `/output/entry.txt`. Deterministic — every run produces byte-identical output. Python 3.13, standard library only, no network access.
